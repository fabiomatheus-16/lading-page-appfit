# Projeto de Lading Page para App fitness

Página com fundo branco e fonte Roboto como principal.
Objetivo é ter uma lading page clean, branca e sofisticada.


# Seção: HEADER:
Logo no canto esquerdo
- A logo é um F em um circulo(feito com CSS)
- O fundo do circulo é VERDE ESCURO

Botão de Download no canto direito
- fundo verde, cor branca
- borda arredondada

# Seção HERO:

A hero deve ter altura 90vh, dividido em 3 áreas horizontais:

Esquerda:
Apenas a Headline, sem ser grande demais, sem destaque(o destaque é o print do app no meio).
"O app perfeito para acompanhar sua vida fitness."

Centro:
Em destaque o imagem images/print_1.png que é um print do app.

Direita:
Uma lista de pontos-chaves sobre o app:
- ❤️ Sáude
- 🏃‍♂️ Exercício
- 🙋‍♂️ Amigos

# Seção de FUNCIONALIDADES:

Vão ser usadas as imagens images/print_2.png, images/print_3.png e images/print_4.png que serão exibidas da seguinte forma:

- print / texto
- texto / print
- print / texto

Ou seja, irá alternar entre o print na esquerda e um texto explicativo na direta, vice-versa.

Descrição breve de cada print para você gerar um texto adequado:

- print_2.png = contagem de calorias
- print_3.png = exercicios especificos (corrida, musculação, etc)
- print_4.png = compartilhamento com amigos

# Seção DE CTA (call-to-action):
Botão grande de download com um texto abaixo dele destacando:
"Totalmente gratuito"

# Seção RODAPÉ:
Apenas com o texto "Todos os direitos reservados"
